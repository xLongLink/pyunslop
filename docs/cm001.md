# CM001: Comment frequency

Warn after more than 10 non-import code lines without a standalone comment.
Function definitions and standalone comments reset the counter; blank lines and
inline comments do not. Multiline and adjacent strings count at their expression
start. Prefer simpler code or a useful explanation, not filler comments.

```example
# Bad
total = 0
total += january
total += february
total += march
total += april
total += may
total += june
total += july
total += august
total += september
total += october

# Good
total = sum(monthly_totals)
```
