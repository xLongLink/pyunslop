# PY016: Prefer pytest tests

This fixed policy flags absolute `unittest` imports, including aliases,
`from` imports, and submodules such as `unittest.mock`. Prefer plain pytest
tests, assertions, fixtures, and `pytest.raises`. Consider `monkeypatch` or
pytest-mock for mocking. Relative and dynamic imports are not resolved, and
the checker does not automatically migrate test suites.

```example
# Bad
import unittest

class AdditionTests(unittest.TestCase):
    def test_addition(self):
        self.assertEqual(1 + 1, 2)

# Good
def test_addition():
    assert 1 + 1 == 2
```
