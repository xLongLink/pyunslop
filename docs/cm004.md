# CM004: No suppression directives

Do not use bare or code-specific `noqa` directives, including file-wide
`ruff: noqa` and `flake8: noqa` forms and case variants. Detection uses real
comment tokens, not string contents. Ruff lint also ignores these directives,
so both the suppression and the underlying violation remain visible. Fix the
issue where appropriate; keep legitimate warnings visible rather than adding
another bypass. Findings remain warning-only.

```example
# Bad
import os  # noqa: F401
value = 1

# Good
value = 1
```
